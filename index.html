☁️ GitHub 자동 동기화 여러 기기·자동 백업

폰·컴퓨터·아이패드에서 같은 데이터를 자동으로 쓰고 싶을 때만 쓰면 돼요(선택 사항 — 안 써도 위 백업으로 충분해요). 한 번 연결하면 일정·토탈·OCS가 GitHub의 wonnae-data.json에 자동 저장·동기화돼요.

🔰 처음이면 여기 (연결 방법 3단계)

① 저장소(repo) 만들기
GitHub에서 새 repo를 하나 만들어요(예: 내아이디/wonnae-sync). Private로 만들면 나만 봐요.

② 토큰(비밀번호 같은 열쇠) 발급
GitHub → Settings → Developer settings → Personal access tokens (classic) → Generate → repo 권한 체크 → 생성된 ghp_… 토큰 복사.

③ 아래에 입력 → [연결 테스트]
repo는 아이디/저장소이름 형식, 토큰은 복사한 ghp_…를 붙여넣어요. 성공하면 이후 자동 동기화돼요.

⚠ 토큰은 비밀번호예요. 남에게 공유 마세요. 이 토큰은 이 기기 브라우저에만 저장돼요.

미연결 — repo·토큰 입력 후 [연결 테스트]를 눌러주세요
